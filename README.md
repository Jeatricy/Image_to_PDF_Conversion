# 图片批量转 PDF 工具

把一个目录（含全部子目录）下的图片批量转换成与图片同名的单页 PDF 文件。

## 功能

- 递归扫描所选根目录及其子目录，识别 `.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp`、`.tiff`、`.tif`、`.webp` 八种扩展名的图片。
- 每张图片在其原位置生成同名 PDF（扩展名改为 `.pdf`），单页输出，保存分辨率参数为 100.0。
- 带透明通道的图片（RGBA、LA 以及带透明色的调色板图）先合成到白色背景再输出；GIF 等多帧图片只取第一帧。
- 默认不覆盖已存在的同名 PDF（脚本顶部的 `OVERWRITE_EXISTING = False`），把该常量改为 `True` 才会覆盖重转。
- tkinter 图形界面：选择目录、开始转换、停止、可滚动日志；转换在后台线程执行，不阻塞界面，停止操作在当前图片处理完成后生效。
- 运行结束统计并弹窗显示「转换成功 / 跳过 / 失败」数量；已存在的 PDF、无法识别为图片的文件计入跳过，其他异常计入失败并在日志中给出具体错误。

## 环境要求

- Python 3.8+（代码未使用高版本专有语法；需使用自带 tkinter 的 Windows Python）
- 依赖：Pillow

## 使用方式

### 方式一：从源码运行

```bat
pip install pillow
python 图像转PDF工具.py
```

运行后在界面中选择「待处理根目录」，点击「开始转换」，日志区会逐条打印处理进度；PDF 与源图片位于同一目录。
